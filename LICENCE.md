## 🧩 About

**PUBG External Menu** is a curated list of PUBG open-source tools:

- **Overlays** — on-screen helpers, layout notes, loot tracker, compass
- **Quality-of-Life Helpers** — keybind manager, overlay notes, config presets
- **Research Notes** — map layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### ESP
- Loot Tracker — highlight nearby items of interest
- Compass Overlay — on-screen direction indicator
- Keybind Manager — customize and save control schemes
- Session Notes — record and review match statistics

### Wallhack
- Map Overlay — mini-map with custom markers
- Zone Timer — display safe zone countdowns
- Route Planner — draw and save paths for study

### Aimbot
- Training Mode Notes — practice aim and movement drills
- Recoil Patterns — visualize spray patterns for study
- Jump & Vault Helper — on-screen prompts for parkour routes
